🛡️ How your data is protected

  • All data is in one SQLite file (hr.db) on the server PC – it is never sent to the internet.
  • Other PCs can only reach the data through this website with a login; the database file itself is not shared.
  • Passwords are stored hashed (scrambled) – nobody, not even the admin, can read them.
  • 5 wrong passwords lock the account for 15 minutes.
  • Idle users are signed out automatically (change the time in Settings).
  • Each role sees only what it is allowed to (Roles & Permissions).
  • A full copy of the database is saved every day in the backups folder (last 30 days kept).
  • Deleted records are wiped from the file, and pages are not stored in the browser cache.
  • Every sign-in and every change is recorded below.
  • Run SECURE-DATA.bat once so other Windows users of the server PC can't open the data files.
